# TypeScript 闯关实施记录

目标：完成独立的 TypeScript 网页闯关，与已有 JavaScript、网络课程共同由 GitHub Pages 发布。课程包含全部 14 大关、102 小节及充足的中等或稍有难度的原创题；每题有提示、解析与对应教程，编程题自动检查类型和适用的实际行为。

## 内容与实现（2026-09-28）

- 已完成 14 大关、102 小节、1020 道题；每节 10 题，包括理解、修复、设计、迁移和不同场景复测。408 道是编程题。小节目录和题目 ID 稳定。
- 固定 TypeScript 6.0.3，并使用真正的语义检查。题目支持正反类型案例、运行时行为、DOM 结构行为、项目配置、声明文件和编译输出检查；限制显式 `any`、断言和忽略诊断等绕过方式，除非题目明确要求。
- 每题有三级提示、解释和专题资料链接；资料来自 xcatliu 教程、TypeScript 官方文档及部分网道页面。51 个资料地址已检查可访问。教程仍保留在原站，网站提供原创短讲和题目。
- 最终综合关包括多文件项目，编辑模型、服务、展示和数据解析；只读应用模块验证文件协作。
- 网页适配桌面和手机，中文输入法组合输入期间不重建输入框。支持草稿自动保存、错误信息与输出检查、提示、跳过、延迟复测、存档导入合并和导出。数据保存在当前浏览器，不会自动云同步。
- `npm run build` 已纳入 TS 严格构建；Pages 工作流运行 TS 单元测试、全题审计与桌面/手机浏览器回归。JavaScript 首页和网络课程已增加 TS 入口。

## 验收证据

- `npm run build`：14 大关、102 小节、1020 题通过严格内容检查。
- `npm run typescript:test`：77 项通过。
- `npm run typescript:audit`：408 道编程题的参考答案全部通过，408 份初始代码全部被拒绝；部分题另检查典型错误实现。
- `npm run typescript:smoke`：此前在 1440px 和 390px 通过；新增首页入口检查后需再次验证。
- 原课程 `npm test`、`npm run audit:strict`、`npm run network:audit`、`npm run network:smoke` 均通过；JS 1800 题、网络 1008 题保持完整。
